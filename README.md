# CS-Tools für Windows

Hier erscheinen die offiziellen portablen Windows-x64-Versionen von CS-Tools. Die EXE enthält Bildschirmlupe, Fadenkreuz und Mauszeiger-Werkzeuge.

Die [Release-Seite](https://github.com/NadoHimself/cs-tools-releases/releases) enthält die verfügbaren Downloads und Versionshinweise. Veröffentlichte Dateien heißen `CS-Tools-Portable-<Version>.exe`.
